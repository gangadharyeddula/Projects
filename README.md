# 🏋️ GNova Fitness

GNova Fitness is a modern, responsive fitness website designed to provide users with an engaging and visually appealing experience. Built entirely with **HTML5** and **CSS3**, the project demonstrates responsive web design principles, semantic HTML structure, and modern CSS techniques.

The website is suitable for gyms, fitness centers, personal trainers, and health enthusiasts who want a professional online presence.

---

# 🌐 Live Demo

**Website:** https://gnova-fitness.bytexl.live/

---

# 📖 Project Overview

GNova Fitness was developed as a front-end web development project with the goal of creating a professional single-page fitness website. The design focuses on usability, responsiveness, and clean user interface elements.

The project showcases:

* Semantic HTML5 structure
* Responsive layouts
* Flexbox and CSS Grid
* Media Queries
* Modern UI/UX principles
* Mobile-first design approach
* Clean and maintainable code
